# Owner store

One per owner: the products this owner runs with self-loop, and (from slice 4 of phase v1) the owner's words, marks,
routes and principles. Managed by self-loop's tools; never edited by hand except `products.json` (RECORDS.md § The owner store).

- `products.json`: the registry. Each product's name, the absolute path of its records repository and its aliases;
  `roots` are folders under which `self-loop tick` reports records repositories nobody registered.
